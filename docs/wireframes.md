\# LIMO simulator: interface wireframes (M2)



The desktop layout has a top bar, a toolbar, and three columns:

editor and machine code (left), datapath (centre), control and

hazard panels (right). Pipeline chart, registers, memory and

narration sit along the bottom. The phone layout uses five tabs.



| Handout item | Where it appears |

|---|---|

| B1 Editor and assembler | Left column: editor, listing, errors |

| B2 Controls | Toolbar: Step, Run, Pause, Reset, Back |

| B3 Datapath | Centre column |

| B4 Control view | Right column, top |

| B5 Hazards | Right column, bottom; Forwarding switch in top bar |

| B6 Statistics and state | Bottom row |

| B7 Freshman mode | Narration panel, EN/ST switch, example menu |



Colour is never the only cue: changed values are bold with a dot,

and bit fields print their names.
